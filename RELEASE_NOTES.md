# Hover Focus v0.3.1 — Early Preview

Hover-based sentence/line focus for Zotero 10, with adjustable dimming, optional native annotations, and Chinese/English settings.

Install the attached `hover-focus-0.3.1.xpi` via Zotero → Tools → Plugins → gear → Install Plugin From File.

Early preview: macOS use only so far; Windows/Linux and compatibility with other reading plugins have not been fully tested. The repository update manifest is now configured. Existing users of earlier builds should manually install this version once. See README for limitations.

---
